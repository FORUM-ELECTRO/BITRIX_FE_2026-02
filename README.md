# Корпоративный портал Битрикс24

**Репозиторий:** BITRIX_FE_2026-02

Репозиторий содержит файлы корпоративного портала, разработанного на платформе «1С-Битрикс24». Проект находится в активной разработке и включает как базовую структуру, так и множество пользовательских доработок.

## 📁 Детальная структура папки `/local`

Вся кастомная логика проекта сосредоточена в папке `/local`. Это стандартное и рекомендуемое место для пользовательских доработок, которое защищает их от перезаписи при обновлениях ядра.

### Основные компоненты:

| Папка/Файл | Назначение и ключевые доработки |
| :--- | :--- |
| **`activities/custom/`** | **Пользовательские действия (активити) для бизнес-процессов.** <br>Содержит кастомное действие `CompanySearchSberActivity` с доработанной логикой обновления токена для интеграции с сервисами Сбера. |
| **`components/bitrix/`** | **Переопределения стандартных компонентов.** <br>Кастомизирован компонент `intranet.ustat` ("Пульс компании") для изменения вывода данных на портале. |
| **`js/`** | **Пользовательские JavaScript-скрипты.** <br>Содержит скрипты для вызова попап-окна подтверждения даты процедуры. |
| **`modules/`** | **Собственные модули проекта.** <br>Включает кастомный b2b-модуль. Кастомный модуль потоков, а также собственный модуль для отслеживания логов. |
| **`php_interface/s1/`** | **Пользовательская логика для сайта (s1).** <br>Здесь ведется активный рефакторинг. Содержатся файлы `init.php`, обработчики событий, классы и константы. |
| **`templates/.default/components/bitrix/`** | **Шаблоны компонентов для стандартного шаблона.** <br>Переопределены шаблоны для работы с зависимыми полями (обработчики и скрипты, управляющие отображением полей в формах). |
| **`tools/`** | **Вспомогательные скрипты.** <br>Содержит скрипт для наполнения highload-блока данными из CSV-файла. |

## 🚀 Основные возможности и доработки

*   **Интеграция со Сбером** — кастомное действие для бизнес-процессов с обновлением токена.
*   **Кастомизация интерфейса** — переопределены компоненты "Пульс компании" и добавлены JS-скрипты для работы с датами.
*   **Управление полями** — реализована логика зависимых полей в формах.
*   **Импорт данных** — скрипт для загрузки справочной информации в highload-блоки из CSV.
*   **Расширение CRM** — добавлена кастомная кнопка "Платежи" в верхнее меню.
*   **Собственный модуль** — разработан b2b-модуль для специфической логики.

## ⚙️ CI/CD: Автоматический деплой

### Схема работы

- **Тестовый сервер** — разработка и тестирование кода.
- **Боевой сервер** — автоматически получает обновления.
- **GitHub** — единый репозиторий, привязанный к обоим серверам.

### Процесс

1. Разработка на тестовом сервере (SSH / VS Code Remote-SSH).
2. Фиксация изменений:
   ```bash
   git add local/
   git commit -m "Описание"
   git push origin main
3. GitHub Actions автоматически деплоит на боевой сервер.
